Konversi model 3D

Gunakan halaman ini jika model 3D WatchOut! direvisi. Hasilnya adalah file watchout-model.js yang dipakai oleh viewer 3D di website.

  1. Di Blender: File › Export › Wavefront (.obj). Centang Normals, UV Coordinates, dan Materials.
  2. Pilih file .obj dan .mtl hasil export di bawah ini, beserta gambar tekstur (misalnya logo watchout.png).
  3. Tekan Buat file model, lalu simpan file yang diunduh ke folder assets/3d/ (timpa file lama).
  4. Muat ulang (refresh) index.html. Selesai.
Opsional, tapi disarankan.
Nama file harus sama dengan yang tertulis di file .mtl.
Pengaturan lanjutan
0 = pakai normal asli dari file OBJ.
Ukuran dibanding seluruh model. Membuang objek "nyasar" yang sangat kecil.
Tulis nama objek, atau nama objek/nama material. Dua baris bawaan adalah potongan kecil yang melayang di model saat ini.
